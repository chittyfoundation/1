# ChittyPrime Builder Fractal

ChittyPrime turns an input spec into a governed build packet with seven layers:

1. Identity
2. Authority
3. Connectivity
4. Execution
5. Evidence
6. Evaluation
7. Evolution

The current implementation emits a scaffold plan, blocker list, next actions, and TY / VY / RY scorecard so promotion can remain gated until the missing authority is resolved.
